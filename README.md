# tuios-rs

A Rust rewrite of [TUIOS](https://github.com/Gaurav-Gosain/tuios), a terminal multiplexer
(several shells in tiled panes inside one terminal). **Early development: not ready for daily use.**

- **Download (Linux x86_64):** <https://github.com/imhameed-dev/tuios-rs/releases/tag/dev-latest>
- **Install and keys (Arch Linux):** [docs/INSTALL-ARCH.md](docs/INSTALL-ARCH.md)
- **What works and what does not:** [FEATURES.md](FEATURES.md)
- **Measured memory, size and CPU, with method:** [docs/PERFORMANCE.md](docs/PERFORMANCE.md)
- **Dependencies and licenses:** [DEPENDENCIES.md](DEPENDENCIES.md)
